# Attribution and distribution

This private prototype adapts `c-mongan/chromatic-docs-mcp` at commit `2de273bd5df743632becc39395645d0a6b3e81c8`. Version 0.2.0 also adapts the citation, guidance, screenshot and evaluation design of the Chromatic quality release from 28 October 2026. Its author is Conor Mongan. The original repository is unchanged.

Bitwarden names and documentation belong to their respective owners. This extension is unofficial and is not affiliated with or endorsed by Bitwarden. It retrieves public documentation on the recipient's computer; no documentation corpus is included in the package. Source links and retrieval dates remain attached to tool results.

Runtime dependency licenses are included in their packages under `node_modules`. The MCPB packing tool is a development dependency and is not distributed in the extension. This prototype is intended for direct private sharing; it has not been submitted to an extension marketplace.
